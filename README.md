# 635 創意發想表

6 人 × 每輪 3 個構想 × 6 輪的腦力激盪表單。參與者匿名自動入座，資料存在 Google 試算表。

## 檔案結構

```
index.html            頁面結構
css/style.css         樣式（含深色模式）
js/config.js          設定：Apps Script 網址、同步頻率
js/api.js             呼叫 Google Apps Script
js/app.js             入座、自動儲存、輪詢同步、畫面
apps-script/Code.gs   後端（貼到試算表的 Apps Script）
```

## 串接 Google 試算表

1. 建立一份新的 Google 試算表。
2. 選單「擴充功能 → Apps Script」，把 `apps-script/Code.gs` 全部貼上並儲存。
3. 右上「部署 → 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 授權後複製「網頁應用程式網址」（結尾是 `/exec`）。
5. 貼到 `js/config.js` 的 `API_URL`。

第一次有人開啟頁面時，試算表會自動建立三個分頁：

| 分頁 | 內容 |
| --- | --- |
| 設定 | 主題、目前輪次、清空次數 |
| 座位 | 座位 1–6 與匿名代號 |
| 構想 | 表單 1–6 × 第 1–6 輪，每列構想 1–3 與更新時間 |

> 修改 Code.gs 後要「部署 → 管理部署作業 → 編輯 → 版本：新版本」，網址才會用到新程式碼（網址不變）。

## 運作方式

- 每 3 秒向試算表讀一次全部狀態（分頁隱藏時暫停）。
- 停止輸入 0.7 秒後自動儲存；換輪或關閉頁面時會立即送出。
- 表單編號由後端依「座位＋輪次」計算，參與者不會寫錯表。
- 主持人按「清空」後，其他瀏覽器會偵測到並自動重新入座。
- 主持人設定沒有密碼保護，知道網址的人都能換輪或清空。
